# MedRef AI

**Your Medical Information. Clearly Connected.**

MedRef AI is a modern, privacy-first, AI-powered personal medical information management and reference platform. It transforms scattered medical reports, prescriptions, and health information into one organized, understandable medical journey.

> **Responsible AI Notice**: MedRef AI provides informational support and document organization. It does NOT diagnose medical conditions, replace healthcare professionals, or provide personalized treatment decisions.

---

## 🌟 Key Features

- **Smart Medical Document Scanner**: Drag-and-drop upload for PDFs, prescriptions, and blood panels with step-by-step extraction visualization.
- **Explain My Report**: Breaks down lab metrics (e.g., Hemoglobin, Fasting Glucose, HbA1c) into plain-language explanations with neutral questions for your doctor.
- **Report Comparison Engine**: Select and compare lab reports across different dates side-by-side (`TEST | EARLIER | LATEST | CHANGE`) with visual trend badges.
- **Chronological Medical Journey**: A unified timeline of all visits, lab tests, scans, and doctor consultations.
- **Ask My Records (Grounded RAG Search)**: Query your medical documents using natural language with direct source citations.
- **Medication Organizer**: Active prescription tracking with daily time schedules (*Morning, Afternoon, Evening, Bedtime*).
- **Doctor Visit Preparation**: Auto-generates an Appointment Brief (recent reports, active medications, custom questions) with downloadable PDF export.
- **Searchable Medical Reference**: Educational knowledge base for medical terms, reference ranges, and verified clinical sources.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS 4 + Custom Glassmorphism Theme
- **Icons**: Lucide React
- **PDF Export**: jsPDF
- **Visual FX**: Canvas Confetti
